## Product and demo

- Organization-based SaaS app with viewer, contributor, content owner, and organization admin roles; tenant-scoped source, application, and assistant access.
- Video/document library, processing jobs, transcript review, approval, citations, assistant feedback, role management, workspace settings, audit log, and in-app operator/product/legal documentation.
- The local demo uses PostgreSQL 16 with pgvector, Redis 7, RustFS 1.0.0 as the S3-compatible development service, FastAPI, Celery, and Angular. RustFS was verified for bucket readiness, seeded object upload, presigned video playback, and source retrieval.

They use a synthetic system voice and illustrative screens, not customer recordings. Demo mode still uses mock transcription/embeddings and does not transcribe arbitrary uploaded video audio.
